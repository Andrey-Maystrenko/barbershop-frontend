# Barbershop Frontend

A React-based Single Page Application for managing barbershop services.

## Features

- 📅 Calendar page: Select barber, date, and time
- 💇 Barber page: Choose hairstyle for the selected barber
- 📋 Service page: Complete service details (client, materials, costs)
- 🔄 Multi-window flow with URL parameter passing

## Tech Stack

- React 18
- React Router DOM v6
- Axios
- CSS Modules
